# Generated API documentation

Run `npm run build:docs` to regenerate the Markdown guides in `docs/` from the templates in this directory. Ordinary API builds do not update the guides.

The guides describe the static `api/v2/` hierarchy, page indexes and direct city details. Use your own deployment as the API base; examples do not imply that a public package version has already been published. See [the project README](../../../README.md) for build, publication and source-attribution details.
