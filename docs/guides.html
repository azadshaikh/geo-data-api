01 / Location picker

Load countries, states, and cities

Build a cascading picker by fetching states after a country is chosen, then cities after a state is chosen. Lists return only essential fields; fetch a detail endpoint when you need more.

JavaScript 
const API_BASE = "https://example.com/api/v2/";

async function getJson(path) {
  const response = await fetch(new URL(path, API_BASE));
  if (!response.ok) throw new Error("Request failed: " + response.status);
  return response.json();
}

async function loadPickerData() {
  const countries = await getJson("countries.json");
  const states = await getJson("countries/us/states.json");
  // In an app, use the state chosen by the user.
  const state = states.data[0];
  const cities = state
    ? await getJson(`countries/us/states/${state.path_key}/cities.json`)
    : { data: [] };
  return { countries: countries.data, states: states.data, cities: cities.data };
}

loadPickerData().then(console.log).catch(console.error);

Replace us with the lowercase country ISO2 and use the selected state's path_key. Fallback keys such as id-2312 are provided by the API.

02 / City search

Search within a country

Load the country’s city-page index and each referenced page, then filter the summaries locally. Normalize the query in the same way as name_normalized so a search for “Sao Paulo” matches “São Paulo”.

JavaScript 
const API_BASE = "https://example.com/api/v2/";

async function getJson(path) {
  const response = await fetch(new URL(path, API_BASE));
  if (!response.ok) throw new Error("Request failed: " + response.status);
  return response.json();
}

function normalizeName(value) {
  return value.toLowerCase().normalize("NFD").replace(/\p{M}/gu, "");
}

let brazilCities;
async function searchBrazilianCities(query) {
  const normalized = normalizeName(query.trim());
  if (!normalized) return [];
  if (!brazilCities) {
    brazilCities = getJson("countries/br/cities/index.json")
      .then(index => Promise.all(index.data.map(page => getJson(page.filename))))
      .then(pages => pages.flatMap(page => page.data))
      .catch(error => {
        brazilCities = null;
        throw error;
      });
  }
  const cities = await brazilCities;
  return cities.filter(city => city.name_normalized.includes(normalized));
}

searchBrazilianCities("Sao Paulo").then(console.log).catch(console.error);

This folds combining marks; it is not full transliteration. Empty countries have an index with no pages. The global index links to every country index. Cache pages for repeated searches.

03 / City details

Find a city by ID

Each city has a JSON file named after its numeric ID. Fetch it directly, and handle a missing ID as a 404 response.

JavaScript 
const API_BASE = "https://example.com/api/v2/";

async function getCity(cityId) {
  if (!Number.isSafeInteger(cityId) || cityId < 0)
    throw new Error("Invalid city ID");
  const response = await fetch(new URL(`cities/${cityId}.json`, API_BASE));
  if (response.status === 404) return null;
  if (!response.ok) throw new Error("Request failed: " + response.status);
  const result = await response.json();
  return result.data;
}

getCity(57995).then(console.log).catch(console.error);

Missing IDs return null in this example. City list pages contain summaries; the direct file has full details.

04 / Shipping

A few deployment tips

  • Pin a dataset or package version when reproducibility matters.
  • Fetch smaller country or state files when possible, and cache responses in your app.
  • Serve the files with your host’s CORS and cache settings appropriate for your clients.
  • Follow every page in the country index for complete city results.
  • Host the website and API with Docker Compose using the Dokploy deployment guide.
