# Geo-Data API v2 Implementation Plan

> Implement the approved v2-only design with focused tests before changing each production boundary.

**Goal:** Ship a static hierarchical v2 API, separate lightweight client, and matching demo, contracts, and Docker deployment.

**Architecture:** Normalize source records once, generate the hierarchy and complete country-page search indexes, preserve one global file per city, and publish a checksum manifest. JSON Schema and shared routes drive the generated OpenAPI/types/discovery outputs.

**Tech stack:** Node.js 22+, npm, JSON Schema, OpenAPI 3.1, static HTML/JavaScript, Docker.

**Spec:** `docs/superpowers/specs/2026-11-09-geo-data-v2-design.md`.
